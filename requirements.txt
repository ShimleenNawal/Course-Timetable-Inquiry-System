# =============================================================================
# C++ build and runtime requirements
# =============================================================================
# This file lists what you need on the machine to compile and run the C++
# Server.exe and Client.exe in this project. Do not run pip against it.
#
# Target: Windows x64, Winsock2 (TCP), C++17 or newer.
# =============================================================================

# -----------------------------------------------------------------------------
# 1. Operating system
# -----------------------------------------------------------------------------
#   Windows 10 or 11 (64-bit). Winsock is part of the OS; no separate
#   "Winsock installer" is required.

# -----------------------------------------------------------------------------
# 2. Compiler and standard library (pick ONE toolchain)
# -----------------------------------------------------------------------------

# Option A - Visual Studio (recommended if you already use VS)
#   Install: Visual Studio 2022 (or newer) with workload:
#     "Desktop development with C++"
#   That pulls in: MSVC compiler, Windows SDK, and the ws2_32 import library.
#   Build: create a "Console App" or empty C++ project, add Server.cpp,
#   database.cpp, Client.cpp, protocol.h, database.h; link ws2_32.lib
#   (Project Properties → Linker → Input → Additional Dependencies).

# Option B - MinGW-w64 (g++) from MSYS2, WinLibs, or TDM-GCC
#   Install: a MinGW-w64 distribution that ships g++ for x86_64 and Win32
#   threads (e.g. MSYS2 package mingw-w64-x86_64-gcc).
#   You need: g++ supporting -std=c++17, and the Winsock headers/libs
#   (normally bundled with MinGW-w64 for Windows).
#   Example build from project root:
#     g++ -std=c++17 -O2 -Wall -Wextra -o Server.exe Server.cpp database.cpp -lws2_32
#     g++ -std=c++17 -O2 -Wall -Wextra -o Client.exe Client.cpp -lws2_32

# -----------------------------------------------------------------------------
# 3. System libraries (linker) - no vcpkg / Conan packages
# -----------------------------------------------------------------------------
#   ws2_32   - Windows Sockets 2 (always link with -lws2_32 on MinGW, or
#              ws2_32.lib in MSVC). No separate download if SDK/MinGW is OK.

# -----------------------------------------------------------------------------
# 4. Optional / not required for the stock assignment
# -----------------------------------------------------------------------------
#   CMake / Ninja - only if you choose to add your own CMakeLists later.
#   vcpkg / Conan - not used by this repo as checked in.

# -----------------------------------------------------------------------------
# 5. GUI (separate from C++; for full stack per README)
# -----------------------------------------------------------------------------
#   .NET 7 SDK - required to build CSharpClient/TimetableClientGui (WPF).
